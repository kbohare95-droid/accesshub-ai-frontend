# AccessHub AI Frontend

React + TypeScript + Vite frontend for AccessHub AI. Backend powered by Supabase Auth, PostgreSQL, Storage and Edge Functions.

## Setup

```bash
npm install
npm run dev
```

Configure `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY` (publishable key) in Vercel or a local `.env`. Do not commit secret/service-role keys.

App deploy is not yet live. The frontend source files will be added next.
